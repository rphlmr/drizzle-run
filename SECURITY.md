# Security

Please report a vulnerability privately through
[GitHub's private vulnerability reporting](https://github.com/rphlmr/drizzle-run/security/advisories/new), never in
a public issue. Include what an attacker can do, the steps to reproduce it, and the affected URL or package.

Reports about the hosted app at [drizzle.run](https://drizzle.run) and about the `@drizzle-run/*` packages from this
repository are both in scope. A vulnerability in Drizzle ORM or Drizzle Kit themselves goes to the
[Drizzle ORM repository](https://github.com/drizzle-team/drizzle-orm/security).
